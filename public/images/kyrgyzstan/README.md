Положите сюда фото Кыргызстана:

- `hero.jpg`  — главная страница (широкое, от 1920x800, до ~400 КБ)
- `cover.jpg` — обложка профиля турфирмы без собственных фото

Допустимые форматы: jpg, jpeg, webp, png. Файлы подхватываются автоматически
после перезапуска `npm run dev`. Проверьте лицензию фото (Unsplash, Pexels,
Wikimedia Commons CC0/CC BY — для CC BY укажите автора).
