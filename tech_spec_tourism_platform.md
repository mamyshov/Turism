# Техническое задание: Платформа для турфирм Кыргызстана

## Название проекта (рабочее)
KyrgyzTour Hub (можно заменить)

## Цель проекта
Создать веб-платформу, где турфирмы и частные гиды Кыргызстана могут зарегистрироваться, создать профиль с фото, видео и PDF-гидами, а туристы — находить их через поиск и фильтры, смотреть медиа-контент и связываться напрямую.

---

## 1. Технологический стек

**Рекомендация для быстрого MVP:**
- Frontend: Next.js (React) + Tailwind CSS
- Backend: Next.js API routes или отдельный Node.js/Express сервер
- База данных: PostgreSQL (через Prisma ORM) или Supabase (Postgres + Auth + Storage "из коробки" — ускоряет разработку)
- Хранилище файлов (фото/видео/PDF): Supabase Storage или AWS S3 / Cloudflare R2
- Аутентификация: Supabase Auth или NextAuth.js
- Хостинг: Vercel (frontend) + Supabase (backend/DB/storage)
- Видео: хранить как ссылки на YouTube/Vimeo (embed) ИЛИ загружать напрямую в Storage — заложить оба варианта

Если Claude Code предложит более простой/быстрый стек для MVP (например, чистый Next.js + SQLite для локальной разработки, миграция на Postgres позже) — это допустимо.

---

## 2. Роли пользователей

1. **Гость (турист)** — просматривает каталог без регистрации
2. **Турфирма/гид (зарегистрированный пользователь)** — управляет своим профилем
3. **Администратор** — модерирует контент, управляет тарифами

---

## 3. Функционал по ролям

### 3.1 Турфирма / гид

**Регистрация и профиль:**
- Форма регистрации: название компании/имя гида, email, телефон, пароль
- Поле "Тип": юрлицо (турфирма) / физлицо (частный гид)
- Загрузка документа для верификации (лицензия, патент, паспорт для физлиц) — статус "На модерации" до одобрения админом
- После одобрения — доступ к личному кабинету

**Личный кабинет:**
- Редактирование профиля: описание, регион работы (список: Иссык-Куль, Ош, Нарын, Джалал-Абад, Баткен, Талас, Чуй, Бишкек и т.д.), языки (кырг./рус./англ./др.)
- Категории туров (мультивыбор): треккинг, конные туры, культурный туризм, гастротуризм, экстрим/адвенчер, эко-туризм, паломнический, зимние туры
- Загрузка медиа:
  - Фото (до 15 штук на профиль, с ограничением размера)
  - Видео (ссылка на YouTube/Vimeo ИЛИ загрузка файла)
  - PDF-гиды/маршруты (загрузка файлов)
- Указание туров: название, описание, длительность (дни/часы), цена, включено/не включено, макс. число человек
- Контакты для связи: WhatsApp, телефон, Instagram, email
- Просмотр статистики: количество просмотров профиля за период (простой график)
- Выбор тарифа (см. раздел 5)

### 3.2 Турист (без регистрации, либо с простой регистрацией для отзывов)

- Главная страница: поиск + популярные направления + топ турфирм (по тарифу/рейтингу)
- Каталог турфирм с фильтрами:
  - Регион
  - Тип тура
  - Язык гида
  - Диапазон цен
  - Длительность
- Карточка турфирмы:
  - Фото-галерея (слайдер)
  - Видео-гиды (embed плеер)
  - Список PDF-гидов для скачивания
  - Список туров с ценами
  - Кнопки связи: WhatsApp (click-to-chat), позвонить, написать email
  - Отзывы и рейтинг (звёзды 1–5 + текст)
- Возможность оставить отзыв (после простой регистрации по email или через Google-логин)

### 3.3 Администратор

- Панель модерации: список новых заявок турфирм на верификацию (одобрить/отклонить с комментарием)
- Управление турфирмами: блокировка, редактирование, удаление
- Управление тарифами и подписками (см. раздел 5)
- Просмотр общей статистики платформы (число турфирм, туристов, просмотров)
- Модерация отзывов (удаление спама/накрутки)

## 4. Структура сайта (карта страниц)

```
/ (главная)
/search (каталог с фильтрами)
/company/[id] (карточка турфирмы)
/register (регистрация турфирмы)
/login
/dashboard (личный кабинет турфирмы)
  /dashboard/profile
  /dashboard/media
  /dashboard/tours
  /dashboard/stats
  /dashboard/billing
/admin (панель админа, доступ только по роли)
  /admin/moderation
  /admin/companies
  /admin/tariffs
/about
/contacts
```

Мультиязычность: кыргызский, русский, английский (использовать i18n-библиотеку, например next-intl).

## 5. Монетизация (заложить в архитектуру с самого начала)

Тарифы для турфирм (хранить в БД как отдельную таблицу, чтобы легко менять):

| Тариф | Цена | Возможности |
|---|---|---|
| Базовый (бесплатно, первые 6 мес.) | 0 сом | Профиль, до 5 фото, без видео/PDF |
| Стандарт | 500 сом/мес | + видео, + PDF-гиды, до 15 фото |
| Про | 1500 сом/мес | + приоритет в поиске, + бейдж "Проверено", + аналитика просмотров |

Плюс: разовое продвижение (топ выдачи на N дней) — отдельная платная опция.

**На старте оплату можно НЕ подключать (просто ручное выставление тарифа админом)**, чтобы не усложнять MVP платёжным шлюзом. Позже добавить интеграцию с местным эквайрингом (например, приём через QR/Elsom/O!Bank либо Stripe для иностранных клиентов).

## 6. Приоритет разработки (для Claude Code — делать поэтапно)

**Этап 1 (MVP):**
1. Настройка проекта (Next.js + Tailwind + Supabase)
2. Регистрация/логин турфирм и обычная аутентификация
3. Личный кабинет: базовое редактирование профиля + загрузка фото
4. Публичный каталог с фильтром по региону и типу тура
5. Карточка турфирмы (просмотр)

**Этап 2:**
6. Загрузка видео (embed + файл) и PDF-гидов
7. Отзывы и рейтинги
8. Панель администратора: модерация новых турфирм

**Этап 3:**
9. Тарифы и биллинг (пока без реальной оплаты — ручное управление)
10. Статистика просмотров для турфирм
11. Мультиязычность (кырг/рус/англ)

**Этап 4 (по желанию):**
12. Онлайн-оплата тарифов
13. SEO-оптимизация страниц турфирм
14. Уведомления (email при одобрении регистрации, новом отзыве)

---

## 7. Важные технические детали

- Ограничение размера загружаемых файлов: фото до 5 МБ, видео до 200 МБ (или только embed-ссылки на старте, чтобы не хранить тяжёлые видео), PDF до 20 МБ
- Все загружаемые файлы проверять по расширению и типу (безопасность)
- Использовать переменные окружения (.env) для ключей API, ничего не хардкодить
- Адаптивный дизайн (mobile-first) — большинство туристов будут заходить с телефона
- SEO: у карточек турфирм должны быть человекочитаемые URL (slug), мета-теги, alt для изображений
